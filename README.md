# AP2-Lerntool FIAE

Lern- und Prüfungstrainer für die IHK-Abschlussprüfung Teil 2 **Fachinformatiker/in Anwendungsentwicklung** (GA1, GA2, WiSo, Fachgespräch).

**Direkt im Browser starten:** https://whiletrueblackobelizk.github.io/ap2-lerntool/

- Keine Installation und kein Konto nötig, läuft auch auf Handy und Tablet.
- Jeder Nutzer hat sein eigenes Lernprofil. Es wird nur im eigenen Browser gespeichert.
- **Lernstand sichern:** „Speichern“ oben rechts lädt eine Spielstand-Datei herunter. Über Einstellungen → Import lässt sie sich wieder einspielen, auch auf einem anderen Gerät. Wer die Browserdaten löscht, verliert sonst den Lernstand.
- Offline nutzen: Repository als ZIP herunterladen („Code → Download ZIP“), entpacken und `index.html` doppelklicken.

Inhalt: rund 900 Aufgaben mit automatischer Bewertung und Teilpunkten, ausführbare SQL-Aufgaben mit Beiblatt, Schreibtischtest, UML-/ERM-Editor, Fehler finden, Rechentrainer, Prüfungssimulationen mit IHK-Note, Lernpfad mit Levels, Einstufungstest, Lernprofil mit Rang, Wissensbaum, Countdown-Plan bis zur Prüfung, Fachgespräch-Training.

## Fehler gefunden?
In jeder Aufgabe gibt es oben rechts den Link **„⚑ Fehler melden“**. Er öffnet ein vorbefülltes [GitHub-Issue](https://github.com/WhileTrueBlackObelizk/ap2-lerntool/issues) mit Aufgaben-ID und Thema. Deine Antworten oder dein Lernstand werden dabei nicht übertragen.
